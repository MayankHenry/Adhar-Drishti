# Aadhaar Drishti 🔍

Aadhaar Drishti is an AI and ML-based analytics project developed for analyzing Aadhaar-related datasets and detecting patterns, anomalies, and suspicious activities using data science techniques.

## 🚀 Live Deployment

🔗 https://adhar-drishti.streamlit.app/

---

## 📌 Features

- Aadhaar data analysis
- Interactive dashboard
- Data visualization
- Correlation analysis
- Fraud/suspicious activity detection
- Exploratory Data Analysis (EDA)
- Statistical insights

---

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 📊 ML & Analytics Concepts Used

- Data Preprocessing
- Exploratory Data Analysis
- Correlation Matrix
- Statistical Analysis
- Data Visualization
- Anomaly Detection
